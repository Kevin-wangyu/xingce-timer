# 🛡️ 防烧屏计时器 · 记录与分析

> 一款专为 OLED 屏幕设计的智能计时工具，集成了 **防烧屏呼吸动画**、**计时记录**、**正确率趋势图表** 和 **数据导出** 功能。  
> 适用于刷题、模考、专注训练等场景，帮助您追踪学习进度，保护屏幕健康。

---

## ✨ 功能特性

- **⏱️ 智能计时**  
  - 支持 **开始/暂停/重置**，计时精确到秒，显示 `HH:MM:SS` 格式。
  - **自动屏幕常亮**（需 HTTPS 环境），防止系统休眠打断您的专注。

- **🫧 防烧屏呼吸动画**  
  - 整个计时数字每 **15 秒** 进行一次 **2 秒** 的淡入淡出呼吸，有效避免 OLED 像素老化。
  - 控制栏自动隐藏，鼠标移动时浮现，减少静态 UI 元素。

- **📝 记录功能**  
  - 记录当前日期、用时、模块（常识/言语/数量/判断/资料）、正确率、错误原因和备注。
  - **编辑** 已有记录，日期和时间字段可自由修改。
  - 数据永久保存在浏览器本地（`localStorage`），关闭页面不丢失。

- **📊 模块正确率趋势图**  
  - 选择任意模块，自动绘制该模块所有记录的 **正确率折线图**（按记录次序排列）。
  - 图表采用暗色主题，与界面风格统一，悬停显示详细日期。

- **📤 数据导出**  
  - 支持导出为 **CSV** 或 **TXT** 文件，逗号分隔，含表头。
  - 自动处理字段中的逗号、换行符和引号，保证数据完整。

- **🖥️ 全屏沉浸模式**  
  - 一键进入全屏，隐藏浏览器地址栏和工具栏，专注体验。

## 🚀 快速开始

1. **下载或克隆** 本仓库，将 `index.html` 保存到本地。
2. **使用支持 HTTPS 的服务器运行**（推荐）：
   - 使用 VS Code 的 **Live Server** 插件。
   - 或使用 Python：`python -m http.server 8000` 并访问 `http://localhost:8000`。
   - 或部署到任何支持 HTTPS 的静态托管（GitHub Pages、Vercel 等）。
3. 在浏览器中打开页面，点击 **“开始”** 即可使用。

> ⚠️ **屏幕常亮功能** 需要 HTTPS（或 localhost）环境，如不支持，计时和记录功能依然正常。

## 🧭 使用指南

### 计时控制
- **开始/暂停**：点击 `▶ 开始` 开始计时，再次点击暂停。
- **重置**：归零计时，并自动释放屏幕常亮锁。
- **全屏**：点击 `⛶ 全屏` 进入沉浸模式。

### 记录操作
- **记录**：点击 `📝 记录`，弹出表单。日期和用时自动填入，您只需选择模块、填写正确率（支持 `80%` 或 `8/10` 自动转换）、错误原因和备注，点击保存。
- **编辑**：在 `📋 查看记录` 中，每条记录右侧有 `✏️ 编辑` 按钮，点击后可修改所有字段（包括日期和用时），保存后自动更新。
- **删除**：在查看记录界面可一键清空所有记录（慎用）。

### 图表查看
- 点击 `📈 图表`，选择模块后 **自动生成** 该模块正确率随记录次序变化的折线图。
- 鼠标悬停数据点可查看具体正确率和对应日期。

### 数据导出
- 在查看记录界面，点击 `📊 导出 CSV` 或 `📄 导出 TXT`，将全部记录下载为文件（含 BOM，Excel 可正常打开）。

## 💾 数据存储

- 所有记录以 JSON 格式保存在浏览器 `localStorage` 中，键名为 `timerRecords`。
- 数据持久化，**清除浏览器缓存或手动清空记录**才会丢失。
- 建议定期导出备份重要数据。

## ⚠️ 注意事项

- **屏幕常亮** 需要 **HTTPS**（或 `localhost`/`127.0.0.1`）环境，否则该功能不可用，但计时和记录不受影响。
- 使用 **全屏** 功能时，某些浏览器可能需要用户手势触发（如点击按钮）。
- 图表模块若无记录，将显示“该模块暂无记录”提示。
- 本工具为纯前端应用，无后端依赖，所有数据仅在本地存储。
